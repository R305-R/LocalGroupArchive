# LocalGroupArchive v0.5.0

إضافة Vencord تحفظ قروبات الـDM محليًا على جهازك، مع مرفقاتها وصورها، وتعرضها في واجهة سريعة شبيهة بديسكورد حتى عند انقطاع الإنترنت.

> LocalGroupArchive لا يتجاوز صلاحيات حسابك ولا يسترجع شيئًا لم يعد ديسكورد يرسله لك. Vencord مشروع طرف ثالث وغير تابع لديسكورد.

## التثبيت السهل على Windows

1. نزّل `LocalGroupArchive-Setup-v0.5.0.exe` وملف الـ`.sha256` من آخر GitHub Release.
2. افتح المثبت. لا يحتاج صلاحية Administrator.
3. المثبت ينزّل Node.js LTS محمولًا ويتحقق من SHA-256 الرسمي، ثم يثبت نسخة ثابتة من أحدث commit لمصدر Vencord الرسمي، ويستخدم إصدار pnpm الذي يطلبه Vencord، ويركب الإضافتين ويبني Developer Vencord.
4. ينزّل Vencord Installer CLI الرسمي ويتحقق من checksum المنشور، ثم يحقن نسخة المطور تلقائيًا في Discord (الأولوية Stable ثم Canary ثم PTB).
5. افتح/أعد تشغيل ديسكورد. الدليل العملي يظلم الشاشة ويضيء الزر المطلوب وحده: Settings ← Vencord ← Plugins ← Search ← Enable.

المثبت يحتفظ باختصارات **Repair** و**Check for updates** في قائمة Start. عند التحديث أو الإصلاح لا تُحذف إعدادات Vencord ولا أرشيفاتك. لو عندك أكثر من نسخة Discord وتبي فرعًا محددًا، شغّل سكربت التثبيت يدويًا مع `-DiscordBranch stable` أو `ptb` أو `canary`.

> ملف v0.5.0 غير موقّع بشهادة تجارية، لذلك قد يعرض Windows SmartScreen تنبيه **Unknown publisher** أول مرة. تحقّق من ملف SHA-256 المرفق في الإصدار قبل المتابعة.

عند إزالة LocalGroupArchive، يشغّل مزيل التثبيت أداة Vencord الرسمية لإرجاع النسخة العادية القابلة للتحديث، ثم يحذف بيئة البناء المدارة. أرشيف `Documents\DiscordLocalArchive` لا يُحذف. وأي userplugins أخرى وُضعت يدويًا داخل البيئة المدارة تُنسخ أولًا إلى مجلد احتياطي تحت `%LOCALAPPDATA%\LocalGroupArchiveUserPluginsBackup`.

## أهم ما تغيّر في v0.5

- عارض افتراضي مثل ديسكورد: لا يبقي أكثر من **300 رسالة** في الـDOM. عند الصعود يحمّل 100 أقدم ويزيل 100 بعيدة، وعند النزول يفعل العكس مع تثبيت موضع القراءة.
- بحث موحد في كل القروبات، وتصدير JSON للقروب المحدد.
- كاش محلي للأفاتارات، صور القروبات، صور/GIF الفيديو المضمن، الملصقات، والإيموجي المخصص؛ المحتوى لا يعتمد على CDN بعد تنزيله.
- عرض الردود، التفاعلات، الملصقات، الاستطلاعات، الأزرار، المكالمات، الرسائل المثبتة، رسائل التطبيقات، والمحذوفة.
- حفظ نسخة سابقة قبل استبدال رسالة معدلة داخل مجلد `revisions`.
- عند تشغيل ديسكورد من جديد، يفحص القروبات المفعلة بخيطين فقط ويلتقط الرسائل التي وصلت أثناء الإغلاق بدون إعادة مسح التاريخ كله.
- تنزيلات بمهلة 45 ثانية، ثلاث محاولات، تحقق حجم للمرفقات، أسماء `.part` فريدة، منع تكرار الوظيفة، وحد أعلى للطابور.
- كتابة ذرية للبيانات والـmetadata، وتسلسل عمليات القرص لكل قروب لمنع السباقات.
- إصلاح ترتيب Snowflake الرقمي، ومشكلة الحذف ثم إعادة الأرشفة في نفس جلسة ديسكورد.
- الإيقاف يلغي صفحات التاريخ والتنزيلات ويغلق خادم الحذف المحلي.
- دليل تفعيل حي داخل ديسكورد بدل الصور الثابتة.

## الاستخدام

اكتب `/localarchive` داخل أي Group DM، ثم اختر الإجراء:

| الإجراء | وظيفته |
|---|---|
| `Start + archive FULL history` | يفعل القروب ويجلب كل التاريخ المتاح |
| `Archive FULL history again` | يعيد المسح ويكمل الناقص بأمان |
| `Snapshot currently loaded messages` | يحفظ الرسائل المحملة حاليًا بسرعة |
| `Wait for attachment downloads` | ينتظر انتهاء طابور الوسائط ويعطيك نتيجة |
| `Auto-capture NEW Group DMs` | يشغل/يوقف حفظ القروبات التي تظهر بعد التشغيل |
| `Open Discord-style HTML viewer` | يفتح العارض المحلي |
| `Open archive folder` | يفتح مجلد البيانات |
| `Check archive health + storage` | يحصي الحجم والملفات ويفحص JSON والملفات المؤقتة |
| `Repair viewer + stale temp files` | يعيد بناء الفهارس وينظف المؤقتات القديمة بأمان |
| `Run interactive setup guide` | يعيد تشغيل دليل الإضاءة العملي |
| `Stop archiving this group` | يوقف القروب مع إبقاء ملفاته |
| `Show status` | يعرض حالة القروب والطابور والأخطاء |

الحفظ التلقائي للقروبات الجديدة يعمل افتراضيًا. القروبات الموجودة لحظة تشغيل الإضافة تُعامل كخط أساس؛ شغّل `Start` يدويًا للقروب القديم الذي تريد أرشفته.

## مكان البيانات والخصوصية

كل شيء يبقى على جهازك داخل:

`Documents\DiscordLocalArchive`

ويتضمن:

- `CHANNEL_ID\messages`: آخر نسخة معروفة من كل رسالة.
- `CHANNEL_ID\revisions`: النسخ السابقة للرسائل المعدلة.
- `CHANNEL_ID\attachments`: المرفقات الأصلية.
- `_assets`: الصور والأفاتارات والملصقات والإيموجي المشتركة.
- `index.html` و`Discord Local Archive.html`: العارض المحلي.

البيانات مخزنة بصيغة واضحة غير مشفرة. أي مستخدم أو برنامج يملك صلاحية قراءة حساب Windows يستطيع قراءتها؛ استخدم BitLocker أو تشفير القرص إذا كان الأرشيف حساسًا. لا تُرسل الإضافة الأرشيف إلى أي خادم. اتصالاتها الخارجية محصورة في Discord CDN لجلب الوسائط التي يعرضها حسابك أصلًا.

زر الحذف في العارض يتصل بخادم مؤقت على `127.0.0.1` أثناء عمل ديسكورد فقط، برمز عشوائي داخل العارض، ولا يستمع على الشبكة. حذف أرشيف قروب ينشئ tombstone حتى لا يعيده الالتقاط التلقائي؛ `Start` أو `Full` أو `Snapshot` يعيد السماح به يدويًا.

## التثبيت اليدوي للمطورين

يتطلب مصدر Vencord، لأن Vencord العادي لا يحمّل userplugins من مجلد خارجي:

```powershell
Copy-Item -Recurse plugin\LocalGroupArchive Vencord\src\userplugins\
Copy-Item -Recurse plugin\LocalGroupArchiveSetup Vencord\src\userplugins\
cd Vencord
pnpm install --frozen-lockfile
pnpm build
pnpm inject
```

أعد تشغيل ديسكورد بالكامل. إضافة `LocalGroupArchiveSetup` مطلوبة فقط لتشغيل الدليل الأول، ثم تصبح خاملة بعد اكتماله.

## حدود مهمة

- لا يمكن حفظ رسالة حُذفت قبل أن تراها الإضافة أو قبل مسح التاريخ.
- لا يمكن متابعة قروب بعد زوال وصول الحساب إليه؛ يحفظ ما وصل للقرص قبل ذلك.
- المكالمة الصوتية نفسها لا تُسجّل. تُحفظ metadata المكالمة والرسائل الصوتية/الصوت/الفيديو كمرفقات.
- الحد الوقائي للمرفق الواحد 512 MiB، والمسح الكامل 500,000 رسالة لكل تشغيل.
- العارض يحمّل فهارس JSON للقروبات في الذاكرة عند فتحه، لكنه يرسم 300 رسالة فقط. هذا يحل ثقل الـDOM؛ الأرشيفات الهائلة جدًا قد تستفيد مستقبلًا من فهرس SQLite/بحث متدرج.
- حذف ملفات الأرشيف من خارج العارض أو تعديل JSON يدويًا قد ينتج مجلدًا ناقصًا؛ أمر Full يعيد بناء المتاح.

## هيكل المشروع

- `plugin/LocalGroupArchive`: منطق الالتقاط، التخزين، التنزيل، والعارض.
- `plugin/LocalGroupArchiveSetup`: دليل التفعيل الحي.
- `installer`: مثبت Windows، الإصلاح، التحديث، وإزالة الإضافة.
- `.github/workflows`: فحص بناء Vencord وإنتاج GitHub Release تلقائيًا عند tag.
- `tests`: اختبارات smoke بلا dependencies خارجية.
